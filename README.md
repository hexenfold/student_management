# Student Management System

A simple CRUD web app built with PHP and MySQL (MySQLi).

## Features
- View all students
- Add a student
- Edit a student
- Delete a student

## Technologies
- PHP
- MySQL (MySQLi)
- HTML / CSS

## How to Run Locally
1. Install XAMPP and start **Apache** and **MySQL**.
2. Copy this folder to `C:\xampp\htdocs\student_management`.
3. Open `http://localhost/phpmyadmin`, create a database named `student_management`, then import `database.sql`.
4. Visit `http://localhost/student_management/`.
